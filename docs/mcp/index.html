MCP Server (macOS)
Last updated: August 2026

What is this?

The macOS app can run a local MCP (Model Context Protocol) server so AI tools like Claude, Cursor, and VS Code can read — and with Pro, edit — your personal vocabulary.

  • Runs only on localhost on your Mac (not exposed to the internet).
  • Protected with a Bearer auth token you copy from Settings.
  • Off by default — enable it in Settings → MCP Server.
  • Free: read-only tools. Pro: full read/write (add/update words, tags, quiz results).

Quick start

  1. Open My Dictionary on Mac.
  2. Go to Settings → MCP Server.
  3. Turn the server On (optionally enable auto-start).
  4. Copy the server URL (default http://127.0.0.1:PORT/mcp) and the auth token.
  5. Paste the matching config into your AI client (configs are also copyable in the app).

Client setup

Replace PORT and YOUR_TOKEN with values from Settings → MCP Server.

Cursor

{
  "mcpServers": {
    "my-dictionary": {
      "url": "http://127.0.0.1:PORT/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Claude Code

{
  "mcpServers": {
    "my-dictionary": {
      "transport": {
        "type": "http",
        "url": "http://127.0.0.1:PORT/mcp"
      },
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

VS Code

{
  "servers": {
    "my-dictionary": {
      "type": "http",
      "url": "http://127.0.0.1:PORT/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Claude Desktop: use an MCP HTTP bridge or Claude Code if your Desktop build does not support remote/HTTP MCP yet. Prefer the in-app copy buttons so the URL and token stay in sync.

Tools

Free (read-only)

  • search_words — search vocabulary by text
  • list_words — paginate the dictionary
  • get_word — full word details by UUID or exact headword
  • list_tags — list tags
  • get_quiz_candidates — words due for review / practice

Pro (write)

  • add_word — add a word or expression
  • update_word — update fields and tags
  • update_meaning — add / update / remove meanings
  • assign_tags_batch — tag many words at once
  • manage_tag — create / update / delete tags
  • record_quiz_result — save chat-quiz results to SRS

Security

  • The server binds to 127.0.0.1 only.
  • Every request needs Authorization: Bearer … with your token.
  • You can regenerate the token anytime in Settings.
  • Leave the server off when you are not using AI tools.

Availability

MCP is a macOS feature. It is not available in the iOS app. You need My Dictionary running on your Mac while the AI client is connected.
