# Website Screenshot Assets

This directory contains the raw iOS and macOS screenshots displayed by the My Dictionary website. It is an asset inventory, not an App Store screenshot strategy.

- `ios-screenshots/` contains the ten portrait iOS images referenced by the localized landing pages.
- `macos-screenshots/` contains the six desktop images referenced by the localized landing pages.
- The pages provide fallback content when an image cannot be loaded.

Keep the existing filenames stable unless every localized page reference is updated in the same change. Optimize replacements for web delivery and verify the gallery and lightbox at desktop and mobile widths.

For App Store positioning, headline copy, visual direction, capture planning, localization, export, and testing, use [`Documentation/APP_STORE_SCREENSHOTS.md`](../../Documentation/APP_STORE_SCREENSHOTS.md) as the single source of truth.
